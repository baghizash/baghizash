# Hi, I'm Baghiz

**BAGHIZ ASSHIDDIQIE ARASYA** — Data Analyst based in Indonesia.

I turn raw data into decisions: data cleaning, analysis, and interactive Power BI dashboards. Most of my work uses Indonesian public data (BPS, PIHPS/Bank Indonesia, USGS/BMKG) and classic business datasets. Every featured project ships with documented data sources, reproducible code, a portfolio deck, and a Power BI kit (star schema + DAX measures), so anyone can rebuild the dashboard and verify the numbers.

- **BI & spreadsheets:** Power BI (DAX, star-schema modeling, PBIP), Excel, Google Sheets
- **Data platform:** Google BigQuery
- **Workflow:** Git & GitHub, Jupyter
